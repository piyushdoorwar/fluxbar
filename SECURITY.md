# Security

FluxBar runs locally, makes no network requests and sends no telemetry. It reads `/proc/net/dev` and writes a usage file under `~/.local/share/fluxbar/`.

If you find a security problem, please report it privately through [GitHub security advisories](https://github.com/piyushdoorwar/fluxbar/security/advisories/new) rather than opening a public issue. You'll get a reply as soon as possible, and a fix will ship as a new release on extensions.gnome.org.
