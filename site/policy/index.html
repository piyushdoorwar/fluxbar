Privacy

Privacy policy

FluxBar runs inside GNOME Shell on your machine. It has no account, makes no network requests and sends no telemetry. The only thing it keeps is a small file of daily usage totals, on your disk.

Last updated 10 October 2026

The short version

  • The FluxBar extension makes no network connections of its own and does not send data to a developer-operated service, because there is none.
  • It reads your network interfaces' byte counters to show speed. It never sees what you browse, which apps you use, where traffic goes or what it contains.
  • Usage history is stored locally as one total per day, for the last 30 days, and you can clear it at any time.
  • This website uses Cloudflare Web Analytics, which does not use cookies or track you across sites.

What the extension reads

Every 1 to 5 seconds (you choose), FluxBar reads /proc/net/dev, a file the Linux kernel provides with a running count of bytes received and sent by each network interface. FluxBar subtracts the previous reading from the current one to get your current speed.

Those counters are totals only. They contain no addresses, websites, hostnames, application names or packet contents, so FluxBar has no way to know what you do online. Interface names such as wlo1 are used in memory to decide which connections to count and are not stored.

What it stores, and where

  • Usage history is saved in ~/.local/share/fluxbar/usage.json: for each day, the date and the total bytes downloaded and uploaded. Days older than 30 are deleted automatically. This file is read only by FluxBar's top bar menu and History page.
  • Your settings (format, units, network source, position, color and so on) are stored by GNOME's own settings system under /org/gnome/shell/extensions/fluxbar/.

Nothing else is written to disk, and neither the file nor the settings are sent anywhere.

No network requests, no telemetry

Neither the extension nor its preferences window opens network connections. There are no analytics, crash reports, update checks, ads or usage tracking, and no account to sign in to. FluxBar works the same with your network unplugged.

Your control over the data

  • Clear your history from FluxBar's preferences: History, then Clear History.
  • Remove everything after uninstalling FluxBar by deleting its history and resetting its settings:
$ rm -rf ~/.local/share/fluxbar
$ dconf reset -f /org/gnome/shell/extensions/fluxbar/

Installing, updates and donations

Installing FluxBar from extensions.gnome.org, and the automatic update checks that follow, are handled by GNOME Shell and extensions.gnome.org, not by FluxBar, under the GNOME's privacy policy. Installing from source downloads the code from GitHub, under GitHub's own policies.

If you choose to donate through Buy Me a Coffee, that payment is handled entirely by Buy Me a Coffee under its own privacy policy.

This website

This site is static and hosted on GitHub Pages. It uses Cloudflare Web Analytics to count page views. It does not set cookies, does not use local storage for tracking and does not fingerprint visitors; it records aggregate figures such as page path, referrer, country and browser type. Fonts are loaded from Google Fonts.

GitHub, Cloudflare and Google may process standard request data such as your IP address when they deliver this site to you, under their own privacy policies.
